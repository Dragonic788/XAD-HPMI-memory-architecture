So, we all know that RAM gross profit is going up and the prices are skyrocketing, which is exactly why this project exists. 
The idea behind this project is to provide hardware developers with means to combat product prices with a cost-effective and efficient design. 
Everything in this repository is licensed under Apache-2.0
If you want to use this concept for a real product, contact me at dragonic.gaming.yt.1@gmail.com
I hope you, the future of hardware, will use this repository safely and extensively!
Also, everything in here is in SV, a simple programming language to simulate hardware. 
P.S. If you really do this, it's inter-compatible with many processor generations and motherboards because of the AVX2-to-XAD_HPMI translation layer.
